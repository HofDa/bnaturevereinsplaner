# Repository fixes — 3 November 2026

The seven findings from the repository audit are addressed. No database migration or development-data reset is required.

| Finding                                       | Change                                                                                                                                                                | Regression coverage                                                                                                                    |
| --------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------- |
| Administrative write queued before demotion   | Core writes acquire the organization lock and reload the caller's current role before making changes. Finance, events, documents and community share the role lookup. | PostgreSQL test holds the organization lock, demotes the caller, releases the lock, and verifies HTTP 403 with the demotion preserved. |
| Successful writes reuse a retry key           | Clear a completed attempt after success; preserve it after failure and avoid clearing a newer concurrent attempt.                                                     | Hook tests cover consecutive identical successes, failed retries, edited requests and concurrent completion.                           |
| CSV formula-prefix escaping differs by module | All six encoders use one shared cell-escaping function, including whitespace/control-character prefixes.                                                              | Prefix/quoting tests plus a real attendance export containing a tab-prefixed user name.                                                |
| Volunteer/compliance dates use UTC            | One business-date service reads the organization's timezone; frontend defaults use the timezone returned by `/me`.                                                    | Winter, summer, DST and non-European timezone tests; completion after organization-local midnight through the API.                     |
| Dependency advisories block CI                | Pin transitive glob 14.0.2 and minimatch 11.0.1 with overrides; preserve the other direct dependency versions.                                                        | Audit passes; production build and runtime checks exercise the affected dependency paths.                                              |
| Item history truncates at 100 loans           | Paginate item history in batches of 25 and include the page in the query key.                                                                                         | Browser scenario navigates a 101-loan history to the final entry.                                                                      |
| Community tests ignore configured test ports  | Derive mutation origins and additional browser-context URLs from `E2E_WEB_PORT`.                                                                                      | Run community on a non-default port in both viewport projects.                                                                         |

Additional refactoring consolidates responsible-user checks, attachment headers, finance query hooks and invalidation, and the browser login helper. Document versions, registration names/waitlist positions, and community options/vote totals are loaded in batches. The registration query ranks the complete waitlist before applying member visibility; hidden poll totals remain hidden.

The former 1,593-line finance ledger screen is split into cashbook, setup and report modules. Feature routes load lazily. The production entry plus its static preload decreased from approximately 1.65 MB to 1.05 MB (about 37%); feature code executes when opened, while the service worker continues precaching static chunks for offline use. Browser runs build one production artifact while retaining separate fresh backend processes for each suite's rate-limit isolation.

Session reads retry transient failures once, while authentication and permission failures remain immediate. A browser regression injects one authenticated `/me` HTTP 500 and verifies that login recovers. This improves handling of the audit's intermittent read failure; it does not establish the cause of the historical database errors.

Service-worker registration lives in a provider mounted before authentication and persists through lazy route transitions. Route-loading fallbacks stay inside the workspace. Offline tests wait for installation before performing a full navigation; the desktop/mobile offline, session-expiry, conflict and revocation checks pass.
